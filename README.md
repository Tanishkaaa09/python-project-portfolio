# 📦 Installation

Clone the repository

```bash
git clone https://github.com/Tanishkaaa09/python-project-portfolio.git
```

Go to the project folder

```bash
cd python-project-portfolio
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Running Projects

Example:

```bash
python "projects/Beginner/calculator.py"
```

```bash
python "projects/Intermediate/QrCodeGenerator.py"
```

